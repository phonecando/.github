# Security

PhoneCanDo lets AI agents use a phone, so a security hole in it matters.
Thank you for looking. Please report it privately, never in a public issue,
pull request or discussion.

## Where to report

Open a private advisory (**Security → Report a vulnerability**) on the repo
it is about:

- the app: [phonecando/feedback](https://github.com/phonecando/feedback/security/advisories/new);
- phone control's code: [phonecando/phone-control](https://github.com/phonecando/phone-control/security/advisories/new);
- how releases are built, signed or attested: [phonecando/distribution](https://github.com/phonecando/distribution/security/advisories/new).

Not sure which? Pick any; we'll move it. Can't use GitHub? Write to
hi@phonecando.app with "Security" in the subject.

## What to send

What you found, the app version and channel (Settings → About), your phone
and Android version, and the steps to show it. A proof of concept helps;
please test only on your own phone and accounts.

## What happens next

We reply within 7 days, keep you posted while we fix it, and agree with you
when to publish. Once the fix ships, we publish the advisory and credit you,
unless you'd rather we didn't. We fix the latest release, so update first if
you can.
